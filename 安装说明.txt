SillyTavern Link 1.0.2 — 电脑与手机双向接续

适用：Windows + SillyTavern 1.19.0，双端访问同一服务器、同一账户。

推荐：通过 GitHub 安装
1. 酒馆 → 扩展 → 安装扩展，输入：
   https://github.com/rong3742rrr-hub/sillytavern-link
2. 勾选“为所有用户安装 / Install for all users”。
3. 下载完成后关闭酒馆服务。
4. 打开酒馆目录下 public/scripts/extensions/third-party/sillytavern-link。
5. 双击 Install.cmd，完成后重启酒馆、刷新页面。
仅粘贴 GitHub 地址不会完成服务器组件的安装。

ZIP 安装：解压完整安装包，双击 Install.cmd，输入酒馆目录。
GitHub 更新：酒馆内更新扩展后，还需关闭服务、再运行 Install.cmd、重新启动。
旧 ZIP 迁移到 GitHub：保存进度、关闭服务，用 Uninstall.cmd 移走旧程序，再按上面步骤安装。数据保留。

首次使用：平时使用的电脑浏览器和原地址建立基准，再用手机接续。
已用过本插件的用户继续沿用已有基准，不要重新建立。
游玩中不会自动刷新；回到旧设备时点“在此设备接着玩”。
建立基准时不用先开 FRP；手机远程访问时电脑、酒馆服务和 FRP 要在线。

手机备份窗口可选“跳过本次备份”或“以后不备份”。
插件数据备份保留 24 小时，服务运行时每分钟检查，停机期间在下次启动补做清理。
当前同步数据不自动删除；酒馆自身备份和安装器恢复副本不受此规则影响。

隐私：同步数据只发到你自己的酒馆服务器，不上传作者服务器或 GitHub。
FRP 访问会经过公网通道，并非纯离线。同步内容可能包含其他插件存于浏览器中的密钥。
公开分享时只分享程序，不分享账户数据、同步快照和备份。

卸载：先关闭酒馆服务，运行 Uninstall.cmd，再重启。
不要仅在扩展管理器中删除，避免留下启动入口和服务器组件。
卸载保留私人数据，程序文件会移到酒馆 backups 下的恢复目录。

详细安装、范围、隐私和限制见 README.md；验证范围见 TESTED.md。
